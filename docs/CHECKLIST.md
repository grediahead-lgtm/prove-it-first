# One-page checklist before you test an idea

- [ ] Rules written with exact numbers and dated (pre-registration).
- [ ] Decision on the close of t, trade at the open of t+1.
- [ ] Instrument list as of the start date (not today's winners); rule for assets that disappear.
- [ ] Fee AND slippage on every trade; doubled-cost replay planned.
- [ ] Criteria fixed (profit at double costs, blocks, drawdown, concentration, beats holds, enough trades).
- [ ] Sealed final window untouched.
- [ ] Attempt ledger started; number of attempts limited (normally one).
- [ ] Someone else (or another AI) reviewed text and code before the run.
- [ ] Data checked: one time zone, no gaps beyond your rule, no negative or empty values.
- [ ] After a pass: only a candidate. Confirm forward on new data before any real money. Education, not advice.
